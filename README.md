# Valorant Recorder

Valorantのプレイをバックグラウンドで自動録画し、試合終了後に取得したタイムラインデータ（キル、デスなどのイベント）と同期して、専用プレイヤーで振り返りができるツールです。

## 主な機能
- **自動録画**: Valorantのログを監視し、試合開始・終了に合わせて自動的にバックグラウンドで録画を行います。
- **メタデータ連携**: 試合終了後、Henrik APIを利用して試合のタイムラインデータ（キル、デス、ラウンド情報など）を自動取得します。
- **専用プレイヤー**: 録画した動画を再生しながら、シークバー上に表示されるキル/デスなどのイベントアイコンをクリックすることで、重要なシーンへ瞬時にジャンプできます。

## 前提条件
- Python 3.10 以上
- Windows OS (Valorantの実行環境)
- [Henrik API](https://docs.henrikdev.xyz/) のAPIキー

※ 録画に必要な `FFmpeg` は、初回起動時に自動的にダウンロード・セットアップされます。
